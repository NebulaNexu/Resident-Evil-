# Resident Evil

Portal fan-made dedicado à franquia Resident Evil, desenvolvido em React com foco em experiência imersiva, estética temática e apresentação de conteúdos sobre os principais jogos, personagens e momentos marcantes da saga.

## Visão geral

Este repositório reúne o projeto de um site/portal para fãs da franquia Resident Evil, com páginas específicas inspiradas nos jogos da série, personagens icônicos e um estilo visual voltado para a atmosfera sombria, tensa e nostálgica da franquia.

## Projeto principal

O código principal está localizado em:

```bash
Projeto Resident Evil website/Projeto-Resident-Evil-Portal-master/
```

## Tecnologias principais

- React
- JavaScript
- React Router DOM
- SCSS / CSS Modules
- AOS
- React Icons
- Swiper
- React Scroll

## Como executar localmente

Acesse a pasta do projeto e rode:

```bash
cd "Projeto Resident Evil website/Projeto-Resident-Evil-Portal-master"
npm install
npm start
```

A aplicação fica disponível em:

```text
http://localhost:3000
```

## Build de produção

```bash
npm run build
```

## Observações

- O projeto foi desenvolvido como uma homenagem fan-made à franquia.
- O ambiente pode exigir a flag `--openssl-legacy-provider` em algumas versões do Node.js.
- O app foi implementado com foco em apresentação visual, navegação temática e conteúdo de fan portal.

## Objetivo

Criar uma experiência de portal web para fãs de Resident Evil, combinando design imersivo, conteúdo informativo e referências visuais da série.

## Destaques

- fan portal temático com foco na atmosfera da franquia
- navegação por jogos e personagens
- páginas com identidade visual diferenciada por título
- uso de vídeos, sons e animações para maior imersão
- layout pensado para uma experiência memorável e visualmente forte

## Roadmap

- ampliar conteúdo e páginas de personagens
- melhorar organização de seções e categorias
- otimizar a responsividade e performance
- adicionar mais conteúdos multimídia e extras
- manter a base do projeto atualizada e mais fácil de evoluir

## Status

Em desenvolvimento contínuo, com páginas e seções sendo expandidas e refinadas ao longo do tempo.
